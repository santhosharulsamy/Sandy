As easy as Python. Compiles to a native binary that runs 15–180× faster.

Write the readable, dynamic code you'd write in Python — add types where they earn their keep — then compile the hot paths to a single small binary that runs at C speed. Sand is what chips are made of; Sandy compiles down to the metal.

fib.sy
# types are optional — add them where they earn their keep
fn fib(n: int) -> int {
    if n < 2 { return n }
    return fib(n - 1) + fib(n - 2)
}

print(fib(30))

What's in the box

A whole language, not a toy.

Two execution engines, a gradual type checker that runs before your program does, a native compiler, concurrency, a package manager, and a real standard library — all built and tested end to end.

SAFE

Gradual types

Annotations are optional. Add them and the checker catches mismatches before the program runs — with zero false positives on dynamic code.

FAST

Native compiler

sandy build lowers the typed subset to C: structs, closures, try/catch, and an optional garbage collector.

EASY

Instant runs

A tree-walking interpreter and a bytecode VM run your code with no build step, so the edit–run loop stays immediate.

CONCURRENT

Tasks & channels

spawn work in the background and talk over channels — share memory by communicating, the Go way.

BATTERIES

17-module stdlib

json, csv, regex, http, math, time, os, random, hashing and more — written in Sandy itself, imported by bare name.

SHAREABLE

Package manager

A manifest, semver dependencies, a lockfile, sandy publish, and an HTTP registry server.

The honest part

What Sandy is — and isn't — yet.

The interpreter is not the fast part. It's written in Python, so it runs Sandy slower than CPython — it exists for instant feedback while you develop. The speed comes from compiling the typed hot paths, where Sandy pulls 15–180× ahead because the output is real C.

The language is done; the ecosystem is young. Sandy won't out-library Python tomorrow — that took Python thirty years and a global community. What Sandy offers today is a coherent lane Python can't stand in: scripting-language ease that compiles to a small, fast, statically-checked binary. The machinery to grow — a package manager and a registry — is already built.

Try it

Three commands.

Sandy needs only Python to run, and a C compiler (cc/gcc/clang) to build native binaries.

your terminal
# run instantly on the interpreter
python -m sandy run app.sy

# type-check without running
python -m sandy check app.sy

# compile to a fast native binary
python -m sandy build app.sy --run
